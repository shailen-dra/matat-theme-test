# Header and menus

The header is a section group shown on every page. Open it from any page in
the theme editor.

## Menus

Create menus in Shopify admin under **Online Store → Navigation**, then pick
them in the header:

- **Menu:** the main menu. Nested items become dropdowns or mega menus.
- **Customer account menu:** the menu shown from the account icon.

## Logo

- **Logo:** your logo image. Without one, the store name is shown.
- **Logo width** and **Logo width on mobile**

## Desktop layout

Choose how the logo and menu sit on desktop. On mobile the logo is always
centered.

- Logo left, menu center
- Logo left, menu right
- Logo center, menu left
- Logo center, menu below
- Logo right, menu center
- Logo right, menu left
- **Index rail (vertical on desktop)**

### The index rail

The index rail turns the header into a numbered column down the left edge of
the page on desktop. Each top-level menu item gets a number (01, 02 …), and
submenus open as a full-height panel beside the rail. Search, account and
cart icons sit at the bottom of the rail.

On mobile, the rail becomes:

- a **numbered index strip** under the header bar, listing your top-level
  menu items in a row that shoppers can swipe, and
- a **menu drawer laid out as the full index**, with the same numbers and
  rules.

The index rail works best with a short main menu of about four to eight
top-level items with short names.

## Menu style

**Uppercase** or **Regular** menu text.

## Behavior

- **Sticky header:** **None**, **Always**, or **On scroll up**.
- **Sticky style:** **Use theme setting**, **Bar** or **Glass bubble**.
- **Transparent on home page:** the header overlays the first section on the
  home page and turns solid on hover and scroll. Set **Text color** and an
  optional **Logo for transparent header** (a light version of your logo).
  Not used with the index rail.
- **Show search** and **Enable predictive search:** predictive search shows
  products, collections, articles and pages as shoppers type.
- **Show country/region selector:** shown when you sell to more than one
  country. Manage countries in **Settings → Markets**.
- **Show language selector:** shown when more than one language is
  published. Manage languages in **Settings → Languages**.
- **Show bottom border** and **Vertical padding**

## Mega menus

A mega menu turns one top-level menu item's submenu into a full-width panel
with up to two featured image cards.

1. Open the Header and click **Add block → Mega menu**.
2. In **Menu item**, type the name of a top-level item in your main menu,
   exactly as it appears, for example `Shop`.
3. Choose whether to **Show "Shop all" link**, pick an **Image shape**, and
   add up to two featured cards, each with an **Image**, **Heading** and
   **Link**.

Add one Mega menu block for each menu item that should use one.

## Announcement and newsletter popup

- To show a scrolling announcement, add a **Marquee** section to the page.
- The **Newsletter popup** section appears after a delay you set in
  **Show after**, and waits the number of days in **Show again after**
  before showing again to shoppers who closed it. Shoppers who subscribe
  don't see it again.
