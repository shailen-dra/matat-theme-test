We're here to help you set up and use Monograph.

## Contact us

Send us a message using our support form: **[SUPPORT FORM LINK]**

Please include:

- your store URL, for example `your-store.myshopify.com`
- the name of the page or section you need help with
- a description of the problem, and screenshots if you can

You'll get an automatic confirmation when your message is sent. We reply
within **two business days**.

## What our support covers

- Help setting up the theme and using its settings, sections and blocks
- Questions about how the theme's features work
- Fixing bugs in the theme: layouts that break, links that don't work, or
  features that don't work as described in this documentation

We fix theme bugs in a future version of the theme, free of charge, and
fix critical bugs as quickly as we can.

## What isn't covered

- Changes to the theme's code, or problems caused by code changes
- Custom designs or features that the theme doesn't include
- Third-party apps and the code they add to your theme. Please contact the
  app's developer.
- Shopify admin, checkout, payments, shipping and domains. Please contact
  [Shopify Support](https://help.shopify.com).

For custom work, you can [hire a Shopify Partner](https://www.shopify.com/partners/directory).

## Before you contact us

- Check the [FAQ](faq.md) and the rest of this documentation.
- Try the problem in a fresh copy of the theme from **Online Store → Themes →
  Add theme**. If the problem doesn't happen there, it's probably caused by
  an app or a code change.
- Make sure you're using the latest version of Monograph.
