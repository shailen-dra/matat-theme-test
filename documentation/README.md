# Monograph documentation

Monograph is an editorial Shopify theme laid out like a printed catalogue:
a numbered index down the side of the page, numbered product cards with a
material line and a ruled price row, index views that list products like a
price list, and ruled, numbered section headings.

These pages explain how to set up and customize the theme. Setting names
are written exactly as they appear in the theme editor, in **bold**.

## Before you edit code

Monograph can be customized fully in the theme editor. If you decide to
edit the theme's code, **duplicate the theme first** (Online Store → Themes →
⋯ → Duplicate) and edit the copy. Code changes aren't covered by our
support, and they're lost when you update to a new version of the theme. For
larger custom work, you can [hire a Shopify Partner](https://www.shopify.com/partners/directory).
